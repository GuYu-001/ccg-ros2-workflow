# Backend Spec — 底层控制编码规范

> 适用于 C++ `rclcpp` 节点、驱动和 `ros2_control`。按项目的硬件与控制器填写具体约定。

## 驱动与控制接口

- 列出受影响的驱动、硬件接口和控制器；核对状态接口、命令接口与关节名称。
- 设备路径、总线和固件版本来自项目配置；记录测试时使用的硬件或替代品。

## 生命周期与实时性

- 检查生命周期状态切换：未激活、通信中断或控制器退出时，执行器如何进入安全状态？
- 对照控制周期检查回调分组、阻塞、内存分配与锁竞争；多线程执行器本身不保证实时。
- 核对 watchdog、命令超时和执行器限幅，特别是最后一条命令不再更新时的行为。

## 验证与硬件安全

- [ ] 先用 fake hardware 或 Gazebo 验证激活、停用和超时路径。
- [ ] 未经明确授权，不给电机上电、不发送 CAN/串口命令、不更改主机权限或放宽安全限制。
- [ ] 无设备或 SDK 时，分别记录已验证的仿真结果和未验证的真机行为。
